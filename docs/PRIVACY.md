# Privacy Policy — PC Doctor

1. **Local Data Only**: All hardware measurements (CPU frequency, disk labels, RAM capacity, running process names) remain strictly in local RAM and are discarded upon application exit.
2. **No Tracking or Telemetry**: PC Doctor has no third-party tracking scripts, analytics beacons, or remote logging hooks.
3. **Transparent Process Visibility**: Process listings are captured exclusively for local presentation in the Task Manager tab.
